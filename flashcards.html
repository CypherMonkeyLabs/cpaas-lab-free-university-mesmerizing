Flashcards

71 terms. The same card is also in the JSON download.

JSON · Printable HTML

CPaaS

The communications platform as a service described in the Platform as a service article: a cloud platform for voice, video, and messaging inside an application.

Source: rooms/cpaas-word.html

PaaS

The broader platform model on the same article. CPaaS is a section inside it, not a second encyclopedia entry that opened on its own.

Source: rooms/cpaas-word.html

Twilio Voice

The API the Twilio article says launched on 20 November 2008 for making and receiving phone calls hosted in the cloud.

Source: rooms/twilio-vonage.html

Vonage communications APIs

One of the three offering groups the Vonage article lists, beside unified communications and contact center applications.

Source: rooms/twilio-vonage.html

Bandwidth Universal Platform

The product heading on the Bandwidth home page that opened, beside APIs for voice, messaging, emergency calling, WebRTC, and authentication.

Source: rooms/five-platforms.html

Bird

The docs site that opened and said email, SMS, and WhatsApp share one platform. MessageBird's developer site also opened. The encyclopedia title did not.

Source: rooms/five-platforms.html

SIP

The signaling protocol Wikipedia describes for starting, keeping, changing, and ending multimedia sessions.

Source: rooms/sip-jobs.html

SIP header field

A name in the IANA registry. The page says the names are case-insensitive.

Source: rooms/sip-jobs.html

Offer/answer

The model in RFC 3264 for using SDP to agree on a session.

Source: rooms/offer-answer.html

tel URI

The URI RFC 3966 specifies for telephone numbers.

Source: rooms/offer-answer.html

RTP

The media transport Wikipedia describes for audio and video, usually over UDP, specified in the RFC 3550 lineage.

Source: rooms/rtp-webrtc.html

WebRTC

The browser real-time project Wikipedia describes. RFC 8825 is the IETF overview of the protocol suite, not a single protocol.

Source: rooms/rtp-webrtc.html

E.164

The ITU-T international public telecommunication numbering plan. The Wikipedia summary says conforming numbers are digits only, at most fifteen.

Source: rooms/e164-did.html

DID

Direct inward dialing. The article also says DDI is the name used in Europe and Oceania.

Source: rooms/e164-did.html

Private domain

The SIP trunking article's name for the part of the network connected to a PBX or unified communications server.

Source: rooms/trunk-domains.html

SIP connection

The Telnyx object for inbound traffic and authentication. Outbound voice profiles are the other object, for outbound routing.

Source: rooms/trunk-domains.html

Messaging profile

The Telnyx object the guide says to create and assign to a number before the send call.

Source: rooms/number-habit.html

Bearer token

The Authorization scheme in the Telnyx sample. The key itself stays out of this repository.

Source: rooms/number-habit.html

SMSC

The short message service center the SMS article says a gateway uses to carry messages over the Internet.

Source: rooms/sms-160.html

Conversation API

The Sinch API the overview describes as channel-agnostic across SMS and the other channels it lists.

Source: rooms/sms-160.html

MMS

The multimedia message Wikipedia describes as an extension of SMS.

Source: rooms/mms-media.html

segmentCount

The field Bandwidth says it returns. For MMS the guide says the value is always 1.

Source: rooms/mms-media.html

A2P 10DLC

The name on Twilio's compliance title and on Sinch's brand and campaign API. The expansion and the tariff were not read.

Source: rooms/ten-dlc.html

Common short code

The short-code article's name for a U.S. inter-operator short number. It is not the same object as a 10DLC campaign.

Source: rooms/ten-dlc.html

Full Attestation

The STIR article's A level: the provider recognizes the entire calling number as the subscriber's.

Source: rooms/stir-letters.html

CNAM

Calling Name Presentation, the name service the Caller ID article describes alongside the number.

Source: rooms/stir-letters.html

SHAKEN

Signature-based Handling of Asserted information using toKENs, the profile Wikipedia attributes to the SIP Forum and ATIS.

Source: rooms/shaken-token.html

PASSporT

The Personal Assertion Token defined in RFC 8225.

Source: rooms/shaken-token.html

Voice Integrity

A Twilio voice-navigation label beside SHAKEN/STIR. This session did not open a separate definition page for it.

Source: rooms/vendor-attest.html

Caller-name query

The Bandwidth voice service for the calling name on VoIP calls in the US and Canada, distinct from the STIR/SHAKEN API sentence.

Source: rooms/vendor-attest.html

PSAP

Public safety answering point. The call center the E911 and PSAP articles describe.

Source: rooms/e911-words.html

NG911

The initiative the Next Generation 911 article describes for text, images, video, and location, intended to replace E911 infrastructure over time.

Source: rooms/e911-words.html

Emergency address

The address Twilio's page says to associate with the phone number used for the emergency call.

Source: rooms/twilio-emergency.html

Basic 911

Twilio's term, on that page, for routing to the PSAP without automatically delivering the number and address.

Source: rooms/twilio-emergency.html

911 Access Dashboard

The Bandwidth emergency host whose base URL begins with service.dashcs.com on the guide.

Source: rooms/bandwidth-911.html

DLR

Dynamic Location Routing, a label on the Bandwidth home page. The behavior was not opened.

Source: rooms/bandwidth-911.html

Video Room

A concept heading on the Twilio Video docs that opened.

Source: rooms/voice-video.html

Text to speech

The Vonage Voice page's feature, described there as over 50+ languages.

Source: rooms/voice-video.html

Verify

The two-factor product Vonage describes, and the separate Twilio docs set. Not a synonym for the messaging API.

Source: rooms/message-verify.html

Silent Authentication

A Vonage Verify channel name. Twilio's navigation says Silent Network Auth. The names are similar and the pages are different.

Source: rooms/message-verify.html

Minimum Monthly Commitment

The Plivo WhatsApp access commitment stated on the prerequisites page, USD 1,000 per month in the US data region or ₹1,00,000 per month in the India data region.

Source: rooms/plivo-commitment.html

WABA

WhatsApp Business Account. The same page says you need one mapped to Plivo, created through an embedded signup or an existing Meta account.

Source: rooms/plivo-commitment.html

Webhook

Twilio's name for the HTTP request it sends your app when an event occurs.

Source: rooms/webhook-direction.html

HTTP 202

The status Bandwidth says it returns when a message has been queued, not when it has been delivered.

Source: rooms/webhook-direction.html

TwiML

Twilio's markup for Programmable Voice. The page that opened lists the verbs and nouns above.

Source: rooms/twiml-ivr.html

ACD

Automatic call distributor. The IVR article says routing can be optimized when IVR is combined with an attendant and an ACD.

Source: rooms/twiml-ivr.html

Media Streams

The Twilio voice feature named for sending live audio to a WebSocket. The message schema was not opened.

Source: rooms/call-flow.html

Refer

A TwiML verb on the voice page. Not, by itself, a full transfer tutorial.

Source: rooms/call-flow.html

Automated attendant

The menu function the IVR article lists beside IVR and ACD.

Source: rooms/ivr-acd.html

TaskRouter

A Twilio docs-home product name. Schema confirm.

Source: rooms/ivr-acd.html

SIP participant

LiveKit's term for a participant that represents a phone caller or callee.

Source: rooms/ai-agents.html

Dispatch rule

A LiveKit telephony object, with trunks, that controls how calls are handled. The rule syntax was not copied.

Source: rooms/ai-agents.html

SIP-WebRTC gateway

A feature the Kamailio article lists. Not a configured server in this repository.

Source: rooms/open-bridges.html

Operator Connect

A Microsoft Teams integration name on the Bandwidth home page, beside Direct Routing.

Source: rooms/open-bridges.html

Figure

A number this lab repeats only when the opened page states it.

Source: rooms/counts-only.html

Registry date

The Last Updated value on IANA's SIP parameters page. Not a product release.

Source: rooms/counts-only.html

Voice Insights

A Twilio voice-navigation name for call and conference summaries. Thresholds were not opened.

Source: rooms/observability.html

Message metadata

What Bandwidth says it keeps. Not the message body.

Source: rooms/observability.html

Confirm

A claim with no URL in this lab, because the page was not opened or did not contain the figure.

Source: rooms/price-confirm.html

See pricing

The pointer on the Vonage pages. The destination table was not opened.

Source: rooms/price-confirm.html

Shared key

What Twilio's webhook docs say you can use to sign webhooks. The key itself is not published here.

Source: rooms/no-secrets.html

Record

A TwiML verb, and also a Jami feature. Neither is a legal permission.

Source: rooms/no-secrets.html

extensions.conf

The Asterisk dialplan file named on the documentation page.

Source: rooms/from-pbx.html

Dual run

A migration idea this lab will not schedule. The week count is confirm.

Source: rooms/from-pbx.html

AGI

Redirect server

One of the three SIP roles the Kamailio article lists.
