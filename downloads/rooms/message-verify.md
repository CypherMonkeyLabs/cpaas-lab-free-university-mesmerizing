# Messaging and verify

Study notes. Not vendor documentation and not legal advice.

- Vonage's Messages API page says it integrates with SMS, MMS, RCS, WhatsApp, Messenger, Viber, and email.
- Vonage's Verify page calls Verify a two-factor authentication product and lists channels including SMS, voice, email, WhatsApp, and Silent Authentication.
- Twilio's Verify navigation lists SMS, RCS, WhatsApp, Push, TOTP, and Silent Network Auth.
- Infobip's docs hub shows a JSON sample with messages, destinations, from, and text, and the navigation includes Verify users.
- MessageBird's developer site opened with SMS and voice quickstarts, including make a call and receive calls.

A login code: write Verify, then one channel from the vendor page you are using. A marketing text: write Messages, not Verify. If the channel is WhatsApp, open the WhatsApp prerequisite before you assume SMS rules apply.
