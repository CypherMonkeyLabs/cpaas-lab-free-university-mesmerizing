# Bridges the open pages actually name

Study notes. Not vendor documentation and not legal advice.

- Kamailio's Wikipedia article lists a SIP-WebRTC gateway among its features, and says Kamailio can be a registrar, proxy, or redirect server.
- Matrix's specification says it is a set of open APIs for decentralised communication, including IM, VoIP signalling, and bridging existing silos.
- Jami's site says Jami can also function as a SIP client, and the Wikipedia article says it is SIP-compatible.
- Bandwidth's home page lists Microsoft Teams Direct Routing, Operator Connect, Genesys Cloud CX, Webex Calling, Zoom Phone, Google Voice SIP Link, and Five9.
- A named customer quote for any of those integrations was not opened.

Pick one hop and write the page. Example: phone, Bandwidth SIP, Zoom Phone, because Zoom Phone is a name on Bandwidth's integration list. Example: browser, Kamailio SIP-WebRTC gateway, SIP core, because that feature is on the Kamailio article. A customer story stays confirm.
