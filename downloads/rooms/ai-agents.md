# AI voice agents, only the sentences that opened

Study notes. Not vendor documentation and not legal advice.

- LiveKit's Agents introduction says the framework lets you add a Python or Node.js program to a LiveKit room as a realtime participant.
- It says LiveKit Cloud includes managed deployment and built-in observability with transcripts and traces.
- LiveKit's telephony page says trunks and dispatch rules extend the room, participant, and track model, and that a SIP participant represents a caller.
- Vonage's Voice page says you can create IVRs and voice bots, with speech to text and WebSockets.
- Twilio's voice navigation names AI agents, Conversation Relay, and Virtual Agent. Telnyx's docs navigation names Agents and LiveKit on Telnyx, marked Beta. Plivo's docs home names Voice AI and SIP trunking toward LiveKit.

Phone caller to SIP trunk to LiveKit room to a Python participant. Cite the telephony page and the agents page. For Twilio, stop at the navigation names Conversation Relay and Virtual Agent unless you open those guides.
