Bandwidth's two emergency hosts

  • Bandwidth's emergency guide says the Emergency Services APIs are hosted with the Dashboard Service and the 911 Access Dashboard.
  • The Dashboard base URL on that page is https://app.bandwidth.com/api/.
  • The 911 Access Dashboard base URL on that page is https://service.dashcs.com/dash-api/xml/emergencyprovisioning/v1/.
  • The page says to pick the API that matches the account, and to ask the account manager if you are unsure.
  • Bandwidth's home page lists an Emergency Calling API beside voice and messaging, and the voice page says you can manage whitelisted IPs for Voice and E911.
