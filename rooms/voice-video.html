Learn it in 5 minutes

  • Twilio's docs home lists Programmable Voice, Programmable Messaging, Verify, Video, Elastic SIP Trunking, and Conversations among its products.
  • The Programmable Voice navigation names outbound calls, incoming calls, gather, conference, IVR phone trees, media streams, and emergency calling.
  • Twilio Video's docs opened with quickstarts named for JavaScript, Android, and iOS, and with Video Room concepts.
  • Vonage's developer home lists Voice, Video, and Messaging as communication APIs, and the Voice page says text to speech covers over 50+ languages.
  • Bandwidth's voice page says you can build a calling application over an HTTPS interface to its voice network.

Flow

What is going on

Count products, not features you hope are included. Twilio Video is a docs set with three named client quickstarts. Vonage lists Video beside Voice. This session did not open a Vonage video overview paragraph, so Vonage video details stay at the navigation level.

The phrase over 50+ languages is the Voice page's own wording for text to speech. It is not a codec list and not a price. Quote it as the page wrote it, or say more than 50 languages in the page's words, and do not turn it into a table of language codes.

Worked example

A web app needs a call and a camera. Write Twilio Programmable Voice plus Twilio Video, or Vonage Voice plus the Video navigation label. Write the TTS line only if you are on the Vonage Voice page.

Quiz

1. Twilio Video's docs name JavaScript, Android, and iOS quickstarts.

True. Those three are on the page that opened.

2. The Vonage Voice page publishes a per-minute price next to the language sentence.

False. It says see pricing. This session did not open a price table.

Ecosystem

Sister pieces sit on the ecosystem page: the glossary, the mind map, the integration map, and the bridges.

  • Video Room — A concept heading on the Twilio Video docs that opened.
  • Text to speech — The Vonage Voice page's feature, described there as over 50+ languages.

Config. Name the product and the client: server voice, or a browser or mobile video SDK. They are different guides.

Troubleshooting. No audio on a video room is a media problem in the WebRTC room, plus the SDK you actually embedded. Do not start by editing SMS.

Bridge. Elastic SIP Trunking is also on the Twilio docs home. It is the trunk product, not the Video Room product.

Mind map, sister technologies, and future hooks live on the ecosystem page.
