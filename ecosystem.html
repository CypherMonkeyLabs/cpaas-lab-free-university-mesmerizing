Glossary

71 terms from the lessons. The same term is listed once.

  • CPaaS — The communications platform as a service described in the Platform as a service article: a cloud platform for voice, video, and messaging inside an application.
  • PaaS — The broader platform model on the same article. CPaaS is a section inside it, not a second encyclopedia entry that opened on its own.
  • Twilio Voice — The API the Twilio article says launched on 20 November 2008 for making and receiving phone calls hosted in the cloud.
  • Vonage communications APIs — One of the three offering groups the Vonage article lists, beside unified communications and contact center applications.
  • Bandwidth Universal Platform — The product heading on the Bandwidth home page that opened, beside APIs for voice, messaging, emergency calling, WebRTC, and authentication.
  • Bird — The docs site that opened and said email, SMS, and WhatsApp share one platform. MessageBird's developer site also opened. The encyclopedia title did not.
  • SIP — The signaling protocol Wikipedia describes for starting, keeping, changing, and ending multimedia sessions.
  • SIP header field — A name in the IANA registry. The page says the names are case-insensitive.
  • Offer/answer — The model in RFC 3264 for using SDP to agree on a session.
  • tel URI — The URI RFC 3966 specifies for telephone numbers.
  • RTP — The media transport Wikipedia describes for audio and video, usually over UDP, specified in the RFC 3550 lineage.
  • WebRTC — The browser real-time project Wikipedia describes. RFC 8825 is the IETF overview of the protocol suite, not a single protocol.
  • E.164 — The ITU-T international public telecommunication numbering plan. The Wikipedia summary says conforming numbers are digits only, at most fifteen.
  • DID — Direct inward dialing. The article also says DDI is the name used in Europe and Oceania.
  • Private domain — The SIP trunking article's name for the part of the network connected to a PBX or unified communications server.
  • SIP connection — The Telnyx object for inbound traffic and authentication. Outbound voice profiles are the other object, for outbound routing.
  • Messaging profile — The Telnyx object the guide says to create and assign to a number before the send call.
  • Bearer token — The Authorization scheme in the Telnyx sample. The key itself stays out of this repository.
  • SMSC — The short message service center the SMS article says a gateway uses to carry messages over the Internet.
  • Conversation API — The Sinch API the overview describes as channel-agnostic across SMS and the other channels it lists.
  • MMS — The multimedia message Wikipedia describes as an extension of SMS.
  • segmentCount — The field Bandwidth says it returns. For MMS the guide says the value is always 1.
  • A2P 10DLC — The name on Twilio's compliance title and on Sinch's brand and campaign API. The expansion and the tariff were not read.
  • Common short code — The short-code article's name for a U.S. inter-operator short number. It is not the same object as a 10DLC campaign.
  • Full Attestation — The STIR article's A level: the provider recognizes the entire calling number as the subscriber's.
  • CNAM — Calling Name Presentation, the name service the Caller ID article describes alongside the number.
  • SHAKEN — Signature-based Handling of Asserted information using toKENs, the profile Wikipedia attributes to the SIP Forum and ATIS.
  • PASSporT — The Personal Assertion Token defined in RFC 8225.
  • Voice Integrity — A Twilio voice-navigation label beside SHAKEN/STIR. This session did not open a separate definition page for it.
  • Caller-name query — The Bandwidth voice service for the calling name on VoIP calls in the US and Canada, distinct from the STIR/SHAKEN API sentence.
  • PSAP — Public safety answering point. The call center the E911 and PSAP articles describe.
  • NG911 — The initiative the Next Generation 911 article describes for text, images, video, and location, intended to replace E911 infrastructure over time.
  • Emergency address — The address Twilio's page says to associate with the phone number used for the emergency call.
  • Basic 911 — Twilio's term, on that page, for routing to the PSAP without automatically delivering the number and address.
  • 911 Access Dashboard — The Bandwidth emergency host whose base URL begins with service.dashcs.com on the guide.
  • DLR — Dynamic Location Routing, a label on the Bandwidth home page. The behavior was not opened.
  • Video Room — A concept heading on the Twilio Video docs that opened.
  • Text to speech — The Vonage Voice page's feature, described there as over 50+ languages.
  • Verify — The two-factor product Vonage describes, and the separate Twilio docs set. Not a synonym for the messaging API.
  • Silent Authentication — A Vonage Verify channel name. Twilio's navigation says Silent Network Auth. The names are similar and the pages are different.
  • Minimum Monthly Commitment — The Plivo WhatsApp access commitment stated on the prerequisites page, USD 1,000 per month in the US data region or ₹1,00,000 per month in the India data region.
  • WABA — WhatsApp Business Account. The same page says you need one mapped to Plivo, created through an embedded signup or an existing Meta account.
  • Webhook — Twilio's name for the HTTP request it sends your app when an event occurs.
  • HTTP 202 — The status Bandwidth says it returns when a message has been queued, not when it has been delivered.
  • TwiML — Twilio's markup for Programmable Voice. The page that opened lists the verbs and nouns above.
  • ACD — Automatic call distributor. The IVR article says routing can be optimized when IVR is combined with an attendant and an ACD.
  • Media Streams — The Twilio voice feature named for sending live audio to a WebSocket. The message schema was not opened.
  • Refer — A TwiML verb on the voice page. Not, by itself, a full transfer tutorial.
  • Automated attendant — The menu function the IVR article lists beside IVR and ACD.
  • TaskRouter — A Twilio docs-home product name. Schema confirm.
  • SIP participant — LiveKit's term for a participant that represents a phone caller or callee.
  • Dispatch rule — A LiveKit telephony object, with trunks, that controls how calls are handled. The rule syntax was not copied.
  • SIP-WebRTC gateway — A feature the Kamailio article lists. Not a configured server in this repository.
  • Operator Connect — A Microsoft Teams integration name on the Bandwidth home page, beside Direct Routing.
  • Figure — A number this lab repeats only when the opened page states it.
  • Registry date — The Last Updated value on IANA's SIP parameters page. Not a product release.
  • Voice Insights — A Twilio voice-navigation name for call and conference summaries. Thresholds were not opened.
  • Message metadata — What Bandwidth says it keeps. Not the message body.
  • Confirm — A claim with no URL in this lab, because the page was not opened or did not contain the figure.
  • See pricing — The pointer on the Vonage pages. The destination table was not opened.
  • Shared key — What Twilio's webhook docs say you can use to sign webhooks. The key itself is not published here.
  • Record — A TwiML verb, and also a Jami feature. Neither is a legal permission.
  • extensions.conf — The Asterisk dialplan file named on the documentation page.
  • Dual run — A migration idea this lab will not schedule. The week count is confirm.
  • UC lab — The sibling course that did open, for the Cisco-shaped material.
  • SIP profile — A FreeSWITCH configuration topic the manual's introduction says it covers.
  • AGI — Asterisk Gateway Interface. The article says AGI programs can use standard streams or TCP sockets.
  • Redirect server — One of the three SIP roles the Kamailio article lists.
  • OpenSIPS — The article's fork of the older SER line. It is named so you do not mix the projects. Its current docs were not opened.
  • Jitsi Videobridge — The selective-forwarding component the Jitsi article names for multi-party video.
  • Matrix — The open federated protocol whose specification introduction was opened. Bridges are named there as a use, not as a list of vendor connectors.

Config. On a CPaaS, record the product (voice, messaging, verify, trunk), the object (number, profile, webhook, SIP connection), and the page title. On Asterisk, record extensions.conf. On FreeSWITCH, record the SIP profile. On Kamailio, record the version folder, such as 6.1.x.

Troubleshooting. If signaling succeeds and audio fails, move from RFC 3261 to RFC 3550. If the create call returns 202 and your app sees nothing, check the webhook status. If a name 404s, mark confirm.
